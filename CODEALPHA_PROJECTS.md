# CodeAlpha Internship Projects

These are the three recent CodeAlpha projects linked from the portfolio.

## 1. Robotics Project
GitHub: https://github.com/vardhan-del/codealpha_task1

Django web application for creating, managing, viewing and exporting robotics-related student reports. The repository README lists student/report fields, automatic word count, report listing/detail pages, PDF export, SQLite storage and a Django template-based interface.

Tech: Python, Django, SQLite, HTML/CSS

## 2. Smart Home Lighting Automation System
GitHub: https://github.com/vardhan-del/codealpha_task3

Django-based automation simulation using PIR and LDR sensor states. It supports automatic and manual light control, automatic/manual mode switching, activity history, a responsive dashboard and Django admin support.

Automation rule: if a person is detected AND the room is dark, the light turns ON in automatic mode.

Tech: Python, Django, SQLite, Automation, HTML/CSS

## 3. Basic Chatbot - Django + Python
GitHub: https://github.com/vardhan-del/codealpha_task4

Beginner-friendly rule-based chatbot using Django and Python. The repository README lists a web chat interface, if/elif response logic, common conversational prompts and a default response for unknown messages. It does not require a database or external API.

Tech: Python, Django, HTML/CSS
